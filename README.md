# familyflow-privacy

Hosts the public FamilyFlow privacy policy via GitHub Pages.

Source: `index.html` (mirrors `PRIVACY_POLICY.md` from the main FamilyFlow repository). Once GitHub Pages is enabled for this repository (Settings → Pages → Deploy from branch `main`, folder `/`), the policy will be live at:

```
https://<github-username>.github.io/familyflow-privacy/
```

## Before treating this as final

The "Data deletion requests" section currently contains a placeholder contact address (`privacy@familyflow.example`). Replace it with the confirmed support email/domain before this page is referenced from the Google Play Console listing or linked from the FamilyFlow app.
